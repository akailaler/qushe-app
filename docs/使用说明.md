# 取舍 · 使用说明

> 像刷短视频一样刷自己的相册。不用下决心整理，想起来就划两下。

取舍是一个**纯本地**的照片 / 视频整理工具。它不改你的相册结构、不上传任何东西，
只做一件事：把「几千张照片该删哪些」这件麻烦事，拆成一次划两下就能做的事。

---

## 30 秒上手

1. 打开应用 → 点「整理照片」，授权访问照片；
2. **左右滑**看下一张；
3. 不想要的**往上滑**，留着的往下划走就行。

就这三步。前 3 张会显示操作提示，之后自动收起 —— 不用背。

---

## 四个入口由你挑

| 入口 | 适合什么时候用 |
|---|---|
| **整理照片** | 日常清相册，从全部照片里随机抽一组 |
| **整理截屏** | 截屏单独成组，废片率最高、删起来最爽 |
| **整理视频** | 视频单独成组，上下滑切换，长按 2× 速看 |
| **整理文件夹** | 想清某个具体目录（Download、Weixin、Camera 之类） |

首页底部还有「到目前为止」：看过多少、删了多少、省了多少空间 —— 攒起来看挺有成就感。
**长按「已删除」这一格可以清零**（只清计数，照片一张不动）。

## 手势速查

### 看照片时

| 动作 | 效果 |
|---|---|
| 左右滑 | 上一张 / 下一张 |
| **上滑** | 删除（进系统回收站，30 天内可捞回） |
| 双击 | 喜欢或收藏（哪个可在设置里选） |
| 单击 | 收起 / 展开界面（底部按钮、缩略图条、上下提示） |
| 双指放大后**缩回再捏合** | 进入「回到那天」——这一整天的照片墙 |
| 双指捏合（在 1× 时） | 同上 |

### 看视频时

| 动作 | 效果 |
|---|---|
| 上下滑 | 切换视频 |
| 长按 | 2 倍速 |
| 双击 | 喜欢或收藏 |
| 侧边按钮 | 喜欢 / 收藏 / 删除（左右位置可在设置里换） |

### 「回到那天」照片墙

| 动作 | 效果 |
|---|---|
| 左右滑 | 一整天连着看（按时间顺序，保留原图比例） |
| 点某一格 | 放大成单张，底部 `i` 可展开完整信息 |
| 上滑某一格 | **标记**删除（松手后这格收缩消失，后面的图补位） |

### 收藏 / 喜欢页

| 动作 | 效果 |
|---|---|
| 点缩略图 | 应用内大图预览（不跳转到别的应用） |
| 长按缩略图 | 直接移除 |
| 「照片 / 视频」右边的「纯观看」 | 切到纯观看后，任何操作都不会改动内容（防误删） |

---

## 喜欢 ≠ 收藏（这是最容易混的一处）

| | 图标 | 存在哪 | 会同步到系统相册吗 |
|---|---|---|---|
| **喜欢** | ❤️ 红心 | 只在取舍里 | 不会。可以随手标记，不必担心污染相册 |
| **收藏** | ⭐ 星形 | 取舍 + 系统相册的「收藏」 | 会（默认自动同步） |

所以：**想留着但不惊动相册 → 点红心；想让系统相册也认这份收藏 → 点星星。**

---

## 删除与回收站

- 「上滑删除」走的是**系统回收站**：照片进手机相册的「最近删除」，30 天后才真正消失；
- 每次删除会由**系统**弹一次确认 —— 这是 Android 对第三方应用的强制要求，
  不是应用多问你一遍（关不掉）；
- 取舍里的「回收站」页会显示每张**还剩几天**，可以直接恢复；
- 设置里可以关掉「删除进回收站」，改成就地永久删除（不建议，除非你很清楚）。

---

## 收藏同步：一个要说清楚的地方

设置 → 收藏里有三项：

1. **同步收藏到系统相册**：整理时点星形，自动写进系统相册的收藏夹；
2. **立即同步**：把已经攒下的收藏一次性补写进去；
3. **同步系统收藏到这里**：反过来，把你在系统相册里手动收藏的，收进取舍。

两个已知限制，先说在前面：

- **只做加法**：在取舍里取消收藏，系统相册那边不会跟着取消；
- **不是所有手机都支持**：部分机型（如 MIUI 12.5）的相册**不读也不写**这个收藏标记，
  这时反向同步会读到 0 条 —— 是系统限制，不是没同步成功。

另外：小米等机型的相册刷新很慢，同步完可能**要重开相册、甚至重启**才看得到。

## 设置里值得改的几项

| 项 | 为什么值得改 |
|---|---|
| **外观 · 深浅模式** | 默认深色；看图为主的界面（预览、视频）永远深色，浅色只影响列表 |
| **每组数量** | 一次抽多少张。太少不够刷，太多做不完，默认值是个折中 |
| **缩略图网格** | 两列图更大、三列一屏看得更多（收藏、回收站、文件夹都跟着变） |
| **只抽没看过的** | 看过的本轮不再出现，刷完一轮自动开新一轮 |
| **双击画面做什么** | 喜欢 or 收藏 —— 取决于你更常用哪一个 |
| **操作栏** | 视频侧边按钮放左边还是右边（右手单手操作建议右侧） |

## 隐私

- **不联网**。整个应用只有「检查更新」会访问一次 GitHub 的公开版本号接口，不带任何标识；
- 不需要「读写存储」权限：只申请**读取**照片/视频，删除通过系统 API 发起，由系统执行；
- 没有账号、没有埋点、没有云备份。代价是：**卸载或换机后，喜欢/收藏记录和统计会清零**
  （照片本身当然不受影响）。

## 常见问题

**Q：删了的照片去哪了？**
进手机相册的「最近删除」，30 天内都能恢复。取舍的「回收站」页也能看到剩余天数。

**Q：为什么某个页面在浅色模式下还是黑的？**
大图预览、视频页这类「看图看片」的界面固定深色 —— 浅色底会把照片衬得像贴在白板上。
浅色只作用在列表和缩略图墙。

**Q：缩略图上那些小角标为什么不跟着变浅？**
角标压在**你的照片**上，底图什么颜色都有可能。深底浅字在任何照片上都读得出来，
浅底深字则会在一张深色照片上直接消失。

**Q：统计数字怎么清零？**
长按首页或设置页「到目前为止」里的**「已删除」**那一格，会弹确认框。

**Q：换了手机，收藏还在吗？**
不在。应用不做云备份（也不联网），记录只在本机。照片本身在相册里，不受影响。

**Q：检查更新说「已是最新」，但我明明看到有新版本？**
它读的是 GitHub 的 latest release，可能有几分钟缓存。过一会儿再点一次。
