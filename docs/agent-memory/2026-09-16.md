### 关键技术结论（复用价值高）
1. **收藏 containerid** 需从 m.weibo.cn 收藏页 Vue 实例取：
   `document.querySelector('.main-top').__vue__.tabs[0].children.find(i => i.name === '我的收藏').gid`
   候选模板：`230413{uid}_-_WEIBO_FAVORITE`。
2. **原图**：微博图床 `/large/` 即原始分辨率（不是 `/mw2000/`）。把 URL 尺寸段
   （`orj360`/`mw690`/`thumbnail`/`bmiddle`/`crop.*`）正则替换为 `/large/` 即可。
3. **实况图**：`mblog.pics[]` 中 `type == "livephoto"`，静态封面在 `large.url`，
   动态片段在 `videoSrc`（MOV）。按 `img_NN.jpg` + `img_NN_live.mov` 同号命名保证配对。
4. **分页**：`m.weibo.cn/api/container/getIndex?containerid=xxx&since_id=xxx`，
   since_id 来自响应 `data.since_id`。
5. **风控**：HTTP 432 是微博特有的风控码；需带移动端 UA + `X-Requested-With`。
   遇到 403/418/429/432 要加倍冷却退避。
6. **不要重试 4xx**（404/410/451）：重试无意义，直接失败并换备用 CDN 地址。

### 踩过的坑
- Windows 上 Bash 工具 PATH 缺 coreutils（ls/grep 报 command not found），
  需 `export PATH=".../PortableGit/versions/1.2.0/usr/bin:$PATH"` 前缀。
- PowerShell 工具捕获 Python 子进程 stdout 会丢内容，改用 `> file` 重定向再 Read。
- 自检脚本自身用 `print` 输出中文在 Windows 控制台会乱码 → 强制
  `sys.stdout.reconfigure(encoding="utf-8")` 并同时写 UTF-8 结果文件。
- 报告文件名用秒级时间戳会互相覆盖 → 加序号去重。
- `index.jsonl` 重复运行会堆积重复条目 → 启动时载入已索引 mid 集合去重。
