## 1.3.73（已构建 + 已装机 + 已入库）

### 新增「按文件夹整理」
首页三个主入口下面一行低调入口 → `ModalBottomSheet` 列文件夹（名称 + 条数 + 类型）→ 选一个开组。
- 数据层：`repo.buckets()`（读 `bucket_display_name` 一列内存统计）+ `sampleFromBucket()`
- **`buildSession(kind, size, bucket)`：bucket 非空时**不套用「只抽没看过的」**（用户明确要求）
- 实测这台机器：图片 **100 个文件夹**、视频 **45 个**；最大 `weibo` 23980 / `Twitter` 22670 / `QQ` 20692
- **已知限制**：`bucket_display_name` 是最后一级目录名，**不同路径的同名文件夹会被合并统计**
- 刻意没用 SQL `GROUP BY`（`COUNT(*)` 要别名，MediaProvider 对 projection 有白名单校验，容易被拒）

### 修 bug：大图里取消收藏会把预览踢掉
根因：`LaunchedEffect(refreshToken) { reload() }` —— 点星 → `mark()` → 通知外层 →
`favoriteCount` 变 → `refreshToken` 变 → **列表 reload → 该项从 items 消失 → 预览关闭**。
修法：`if (previewIndex == null) reload()` —— 大图打开期间不重建列表；
退出时 `onDismiss` 里靠 `listDirty` 补一次刷新。

## 1.3.74（已构建 + 已装机 + 已入库）

### 时间格式改成两个独立开关（四种组合）
`relativeDates` + 新增 `absoluteDates`，默认「只相对」保持旧行为。
- 只相对：primary=`3 天前`，secondary=`文件夹 · 大小`
- 只具体：primary=`2020/6/6`
- 都显示：primary=`3 天前`，secondary=`**2020/6/6** · 文件夹 · 大小`
- 都不显示：`InfoPill.primary` 传 null，只渲染第二行

**`InfoPill(primary: String?)`** 现在支持空第一行。
`infoPillPrimary/Secondary(item, relative, absolute)` 是唯一来源，三处调用点统一传。

### 修：一年前会拼上具体日期
`relativeDayLabel` 曾经 `else -> "${days/365} 年前 · ${target.format(...)}"`。
**「相对时间」这个函数只该输出相对时间一种表达** —— 要同时显示具体日期是调用方另起一行的事。

### 首页「整理文件夹」改成第 4 个 EntryCard
原来做成低调的一行，用户反馈"没沿用另外三个的风格"。现在和它们完全同构：
`title=整理文件夹` / 副标题带例子 / `showCount=false`（它背后没有"多少条"）/ 新增强调色 `AccentFolder`（暖橙）。

### 预览支持下滑退出（MediaPreviewOverlay）
移植 `DayZoomView` 的手感：跟手位移 + 同时淡出，松手时**距离 ≥ 0.22 屏高 或 速度 ≥ 1200px/s** 算退出。
**认领手势前必须过三道关**（这屏里还有 HorizontalPager 和 ZoomableImage）：
① 越过 touchSlop 后判**主轴**，横向优先就放手；② 只有向下算；
③ **`change.isConsumed` 为真就放手** —— 子节点在 Main pass 先拿到事件，
这个判断比额外维护 zoomed 状态更可靠。
`graphicsLayer{alpha/translationY}` 必须写在 `.background()` **之前**，否则黑底在 alpha 层外、永远不透明。
