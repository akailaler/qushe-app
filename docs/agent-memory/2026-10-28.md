可完善项按优先级记在这里，作为后续版本 backlog：

### 值得做
1. **无备份/恢复**：`allowBackup=false` + 全工程无 SAF 导入导出 ⇒ 卸载/换机后
   收藏、喜欢、回收站记账、统计全丢且不可恢复。建议 `Prefs` + `IdSetStore` 导出 JSON。
2. **Android 14 部分授权**：清单声明了 `READ_MEDIA_VISUAL_USER_SELECTED`，
   但 `Permissions.REQUIRED_MEDIA_PERMISSIONS` / `hasPermissionFor` 只认
   `READ_MEDIA_IMAGES` ⇒ 用户选「选择部分照片」时会被判成未授权（**待 Android 14 真机实测**）。
3. **视频不接管音频焦点**：`VideoSessionScreen.kt:215` 建 ExoPlayer 时没有
   `setAudioAttributes(..., handleAudioFocus = true)`，后台音乐会和视频叠音。
4. **无批量操作**：搜不到 selectionMode/多选；收藏页与回收站只能逐条处理。
