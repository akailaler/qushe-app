# 2026-10-19

## 1.3.77（三个用户反馈）

### ① 角标优先级：截屏 > 长图
瀑布流原来 `isLongImage -> "长图"` 排在 `SCREENSHOT -> "截屏"` 前面，
所以截屏长图标成"长图"。用户明确要求：**既是截屏又是长图 → 标截屏**。
（整理页本来就是截屏优先，只有瀑布流反着。）
**教训：这类"优先级"是我自己拍的，用户有明确偏好时以他为准，别用"信息量"论证。**

### ② 瀑布流长图放大后拖不动、也不清晰 —— 又是 `contentRatio`
DayViewScreen 给 ZoomableImage 传了 `contentRatio = photoRatio`，
而**整理页传的是 `null`**（1.3.65 修过一次，结论就写在代码注释里）。
两个症状同源：`snapScale` 被压到 1~1.25（放不大、解码也按容器 ⇒ 糊），横向 `panLimit=0`（拖不动）。
修法照整理页：长图 `contentRatio = null` + 传 `sourceSize`（原始像素）给解码封顶。
**教训：同一个组件的两个调用点传参不一致时，先看哪个是"有注释解释过的"那个。**

### ③ 文案清单（用户要"全部文案列出来自己改"）
生成 `文案清单.md`（工作区根 + 仓库 docs 各一份），316 条，按页面分组，
带编号 / 行号 / 当前文案 / 空着的"改成"列。
⚠️ 第一版把 `if (x) "A" else "B"` 拼成了「取消喜欢喜欢」——
**同一行的多个字符串必须分开列，只有整行以 `+` 结尾才是真正的跨行拼接。**

### ④ 「同步时闪一下的白方块」= 系统授权弹窗，无解
收藏页/提示条全是深色（Ink 0xB、Surface1 0x16161A、Surface2 0x1F1F25），
代码里没有任何白色元素；`MediaStore.createFavoriteRequest` 必然弹系统确认框。
**这是 Android 的强制机制，不是我们的 UI，取消不了。**
能改善的只有"弹几次"：当前 20 条/批（276 条 = 14 次），调大能减少次数但要实测弹窗能否出来。
