# 2026-10-29

## 1.5.0（皮肤系统 / 下滑透出上一级 / 顶部提示）

### ① 下滑退出要"透出上一级画面"
原来会话页 `.background(Ink)` + `PhotoLayer` 也铺了一层不透明 Ink ⇒ 下拉时背后一片黑。
改法：
- 三个位移量（offsetX/offsetY/dismissProgress）从 `if (current != null)` 内部**提到外面**，
  否则根背景的 modifier 读不到；
- 根背景改成 `.drawBehind { drawRect(Ink.copy(alpha = 1f - pull)) }`，
  `pull = offsetY.value / (屏高 × 0.22)` —— **在绘制阶段读 Animatable，不触发重组**；
- `PhotoLayer` 不再自己铺底色（它一铺就把下面盖死）；
- 四处 `chromeAlpha` 乘上 `(1 - pullAlpha())`，否则顶栏/底栏会孤零零浮在首页上。
AppRoot 里主界面**一直都在**（`Box { Scaffold{...}; when(session){...} }`），所以透出是免费的 ——
这一点先确认了结构才动手。

### ★ 皮肤 = 一个色相 + 浅/深两版（和「深浅模式」正交）
`QusheSkin(id, name, light: QushePalette, dark: QushePalette)`；
每套只写 11 个种子色，其余由 `skinPalette()` 推导：
- surface2/3 = lerp(卡片色, 文字色, 6% / 13%)（深色往上提、浅色往下压）
- 浮层：深色半透明黑、浅色半透明卡片色（78% / 82%）
- 渐变遮罩：深色 = 底色带 80%/90% 透明度，浅色 = 透明
**加一套皮肤只改一处**，`QusheSkins` 列表顺序即色卡页顺序。
`ForceDarkPalette` 改成用 `QusheColors.skin.dark`（不是默认那套），否则浅色皮肤的视频页会突变。

### ★★ 设计稿的主色不能直接当"选中态文字色"
给的柔桃 `#E8BFB0` 放在 `#FFF9F4` 上对比度只有 ~1.7，而 `AccentKeep`
同时用于底部导航选中文字、星形、勾选 —— 会糊成一片。
做法：**用对比度反算**，脚本按色相只调明度，把关键配对压到目标值：
正文 ≥10、次要 ≥4.6、提示 ≥3.1、删除 ≥4.0（浅色）/ 4.6（深色）。
这套脚本很好用：给定 (底色, 原色, 目标) 二分出最近的可读色，保持色相不变。
**以后加皮肤先跑这个，再肉眼确认。**

`左右滑下一张 · 上滑删除 · 下滑退出`（胶囊会自动变宽，不用改布局）。

### ③ 色卡页
`ui/settings/SkinPicker.kt`：Dialog 全屏 + 2 列网格，每张卡**左右各一半**（浅/深），
里面用该皮肤自己的颜色画小色块（不能用当前主题画，否则所有卡长得一样）。
设置页第四颗胶囊「更多」，选了皮肤后显示皮肤名。
