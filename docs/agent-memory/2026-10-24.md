# 2026-10-24

## 1.3.98（浮层方案：放弃实时模糊，改"通透白卡片"）

### 为什么不用模糊了
1.3.96/97 用的是"把同一张照片再画一份糊掉"当玻璃底。两个硬伤：
1. **背后是纯白/浅色图时糊完还是白的**，再叠那层 40% 白就变成一块灰 —— 用户原话"灰灰的、有点脏"；
2. **Android 12 以下没有 `Modifier.blur`**，同一套 UI 在旧机上直接退化成死白块。
加上实时模糊本身要额外解一张图 + 每帧绘制，性价比很低。

### 现在的做法（抄的是"半透浅白 + 细描边 + 轻阴影"）
浅色调色板：
- `overlaySoft = 0xBFFFFFFF`（白 75%，圆钮）
- `overlayStrong = 0xC4FFFFFF`（白 77%，胶囊）
- `overlayBorder = 0x14000000`（黑 8%，**浅色下救命的那条线**）
- 阴影：`Modifier.overlayShadow(shape)` —— 2dp、黑 12%，只在浅色返回，
  深色返回 `this`（半透明黑本来就不需要阴影）。
深色完全不变（黑 40%/70% + 白 15% 描边）。
覆盖组件：`RoundActionButton` / `DayCircleButton`（瀑布流四角）/ `InfoPill`。
顺手删掉了 `Frosted.kt` 和所有 `backdrop` 参数（调用点不用再传东西，组件自己判断主题）。

**规律：浅色下"半透明白"必须配一条深描边，否则在浅色照片上边界会消失。**
白底上想做出"材质感"，阴影比模糊有效得多，而且不要钱。

### 回收站角标（浅色）
右下角原来是黑底浅字，浅色界面上那块黑太抢眼（用户）。改成和**左上角天数角标**同一套：
无底色 + 白字 + 3dp 描边阴影。深色保持黑底不变。
