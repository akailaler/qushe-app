## 1.3.98（浮层方案：放弃实时模糊，改"通透白卡片"）

### 为什么不用模糊了
1.3.96/97 用的是"把同一张照片再画一份糊掉"当玻璃底。两个硬伤：
1. **背后是纯白/浅色图时糊完还是白的**，再叠那层 40% 白就变成一块灰 —— 用户原话"灰灰的、有点脏"；
2. **Android 12 以下没有 `Modifier.blur`**，同一套 UI 在旧机上直接退化成死白块。
加上实时模糊本身要额外解一张图 + 每帧绘制，性价比很低。

### 现在的做法（抄的是"半透浅白 + 细描边 + 轻阴影"）
浅色调色板：
- `overlaySoft = 0xBFFFFFFF`（白 75%，圆钮）
- `overlayStrong = 0xC4FFFFFF`（白 77%，胶囊）
- `overlayBorder = 0x14000000`（黑 8%，**浅色下救命的那条线**）
- 阴影：`Modifier.overlayShadow(shape)` —— 2dp、黑 12%，只在浅色返回，
  深色返回 `this`（半透明黑本来就不需要阴影）。
深色完全不变（黑 40%/70% + 白 15% 描边）。
覆盖组件：`RoundActionButton` / `DayCircleButton`（瀑布流四角）/ `InfoPill`。
顺手删掉了 `Frosted.kt` 和所有 `backdrop` 参数（调用点不用再传东西，组件自己判断主题）。

**规律：浅色下"半透明白"必须配一条深描边，否则在浅色照片上边界会消失。**
白底上想做出"材质感"，阴影比模糊有效得多，而且不要钱。

### 回收站角标（浅色）
右下角原来是黑底浅字，浅色界面上那块黑太抢眼（用户）。改成和**左上角天数角标**同一套：
无底色 + 白字 + 3dp 描边阴影。深色保持黑底不变。

## 1.3.99（三态保持不住 / 提示自动收 / 网格列数统一）

### ① 「完全空白」态翻页后被叫回来：多写者
`onZoomedChange` 里是**无条件** `chromeHidden = isZoomed`。
翻页时新图从 1x 开始，`ZoomableImage` 必然回调一次 `false`
⇒ 刚切到沉浸态（stage③），滑一张就被强制显示回来。
**和之前那条"一个 state 多写者时，每个写者只写自己拥有的那次变化"是同一个病。**
改法：记 `wasZoomed`，只在 `isZoomed != wasZoomed` 时写；
并且写的时候同步 `chromeStage`（放大→2、缩回→0），否则 stage 和实际显隐会不同步，
表现成"点一下没反应"。

### ② 底部操作提示
「单击展开缩略图 · 双指放大 · …」原来只要胶片栏收起就一直挂着。
加 `hintDismissed`，`LaunchedEffect(index) { if (index >= 5) hintDismissed = true }` ——
翻过五张就永久收起（本次会话）。

### ③ 收藏 / 回收站网格列数
两处原来是 `GridCells.Fixed(3)` 写死。改成和「整理文件夹」共用
`Prefs.folderColumns`（AppRoot 往下传 `columns`）。
设置项文案：**「文件夹网格」→「缩略图网格」**，
副标题「整理文件夹、收藏、回收站每行放几个。两列图更大，三列一屏看得更多」。

## 1.4.0（同名文件夹合并 / 设置页收尾）

### ① 「整理文件夹」同名合并（方案 2）
`buckets()` 是分别扫 images / video 两张表再拼的，**同一个文件夹会出两条**
（照片一条、视频一条），网格里就是两格同名、按各自数量插在不同位置。
以前靠 `key = "kind-name"` 保证不冲突，但看起来像两个文件夹。

现在 `HomeScreen.FolderSheet` 里先 `groupBy { it.name }` 合成 `FolderGroup`：
- 副标题：`1,204 张 · 38 个视频`（千分位，只有一类时只写那一类）
- 封面取**数量多**的那一类（数量相同取照片）
- 只有一类 → 直接开；两类都有 → 弹「整理照片 / 整理视频」二选一
- 「共 N 个」改用合并后的 `groups.size`（以前把两类都算进去，偏大）

**二选一没开 AlertDialog**：FolderSheet 本身已经是一个 Dialog 窗口，
再开一个窗口，"点外面关的是哪个"很难控制。直接在同一个 Surface 里铺遮罩层，
z 序完全可控（记忆里那条"Dialog 是独立窗口"的变体）。
列表 key 也从 `kind-name` 改成 `name`。

### ② 设置页「检查更新」并入版本行
原来一整栏「检查更新」+ 下面又一栏版本号，两处说的是一件事。
现在一行：左边 `取舍 1.4.0` + 状态/设计说明，右边一颗「检查更新」
（查到新版本变「去下载」，检查中显示「检查中…」）。
⚠️ 版本号仍是**硬编码字符串**：`verify.py` 靠正则 `"取舍 x.y.z"` 做四处一致校验，
改成 `$currentVersion` 会让这项检查失效（这次没动，将来要改得同步改 verify.py）。

### ③ 其他
- 网格设置副标题精简成「两列图更大，三列一屏看得更多」
- 整理页底部操作提示：翻过**三张**就收起（原五张）
- **版本号进入 1.4.x**（versionCode 148）

# WeiBack-rs 1.9.0（commit b4eff13，10 files, +343/-39）

1. **看图点击语义**：原来任何点击都 `onClose`，等于没法看细节。
   改：点图片 = 放大 2.5x（以点击处为 origin）/再点还原；点空白才关。
   图片容器 `stopPropagation`，外层 viewer 挂 `onClick={onClose}`。
2. **★ 滚轮缩放不生效的根因**：React 的 `onWheel` 是挂在根容器上的
   **passive 监听器**，里面 `preventDefault()` 被忽略。改原生
   `addEventListener('wheel', h, { passive: false })` 挂到 viewer 元素，
   顺带整屏任意位置都能缩放。**以后凡是需要 preventDefault 的
   wheel/touchstart，别用 React 合成事件。**
3. **★ 分批加载卡片乱跳**：CSS `columnCount` 多列布局在内容增加时会
   **重排所有列**（已读卡片被挤到下面，新内容跑到上面）。
   改 JS 瀑布流：按"当前最短列"分配（`estimatePostHeight` 用
   文字行数 + 图片行数估算），追加只往列尾长。列数用 `useMediaQuery`
   跟随 sm/md 断点，变化时重算。
4. **FloatingActions**：右下角堆叠 —— 删除（回收站 + 选中数角标，
   未选中时 toast 提示）在上，回到顶部在下。内容浏览页/本地作者页接入，
   跟踪页仍只用回顶。
5. **缩略图预热**：`save_picture` 写完原图立刻 `tokio::spawn` 生成缩略图
   （字节还在内存，不用重读盘），用独立 `WARMUP_SLOTS(2)`，
   不与浏览请求的 `THUMBNAIL_SLOTS(4)` 抢资源。
   **老图片不受益**（只对新下载的生效），说明里已注明。

## 1.4.1（统计清零搬家 / 几处视觉修正）

### ① 统计清零：设置页 → 首页长按「已删除」
- 删掉设置页最底部的「统计清零」栏、`AlertDialog`、`onStatsReset` 参数。
- 首页 `HomeScreen` 新增 `onResetStats`，给「已删除」那格挂
  `pointerInput { detectTapGestures(onLongPress = { confirmReset = true }) }`，
  确认框放在 HomeScreen 里，确认后调 `onResetStats()`。
- 清零逻辑（6 个 prefs 字段归零 + 刷新 stats）从 AppRoot 的调用点搬成参数传递。
- 用 `detectTapGestures(onLongPress=)` 而不是 `combinedClickable`：这格本来不可点，
  不需要 opt-in，也不会和别的手势打架。

### ② 设置页版本行重排
版本号和「检查更新」**同一行**，说明文字另起一行。
之前把按钮放在"版本 + 说明"这一列里，视觉上落在说明那一行（用户反馈）。

### ③ 文件夹副标题被圆角削掉
`FolderCell` 原来是 `Column(Modifier.clip(RoundedCornerShape(14.dp)).clickable(...))` ——
**clip 作用在整列上**，底部副标题被下两个圆角切掉一截。
改成只让封面 Box 自己 clip，Column 只保留 clickable。
**规律：圆角要加在需要圆角的那一层，不要加在包着文字的容器上。**

### ④ 回收站角标
- 右下角（视频时长 / 截屏）整块删掉，用户不需要。
- 左上角（剩余天数）原来是"纯文字 + `shadow(3.dp)`"——阴影本身就是模糊，
  字被糊了一圈，反而更难认。改成**很小的深色底 + 亮字**（`BadgeScrim` + `BadgeText`），
  紧急色新增固定值 `BadgeAlert`（#FF8A9B），不跟主题翻。

### ⑤ 版本号硬编码 vs BuildConfig（讨论过，**没改**）
现状：`SettingsScreen.kt` 里 `"取舍 1.4.1"` 是手写字符串，与 gradle 的 versionName 无关联；
`verify.py` 用正则 `"取舍 x.y.z"` 抓它做"四处一致"校验。
改成 `BuildConfig.VERSION_NAME` 的代价：
- gradle 要开 `buildFeatures { buildConfig = true }`（AGP 8 默认不生成）；
- `verify.py` 那项检查要删掉/改写（否则抓不到字符串会失效）；
收益：版本号只剩一个真源，发版少改一处（历史漏改过两次），R8 会内联无运行时开销。
