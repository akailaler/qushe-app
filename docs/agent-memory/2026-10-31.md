## 2.0.0 配色推翻重做：配色优先，一套成对（22:20）

用户否掉了「西湖景 + 浅深分开选」这一版，两个要求很关键：
1. **配色本身要好看协调，不能为了名字硬凑** —— 名字只是配色的注释，不是配色来源。
2. **回到"一套含浅深"，但色卡保持左右并排**：挑一次整套生效，不要分开选两道题。

### 做法
先定 8 套配色（绿 / 蓝 / 橙 / 紫 / 金 / 青 / 粉 / 橄榄），跑对比度，
**再用 AWT 画总览图看整体** —— 第一版的深色底明度全挤在 L* 8–12，八套缩在图里像一堆黑；
把底色明度分三档（#0A1A19 / #15101F / #241610）后才有层次。**这一步必须做，
只看单个色值判断不了"八套放在一起好不好看"。**

名字是最后配的，八个典故：空山新雨（王维）、雪夜访戴（王子猷）、落霞孤鹜（王勃）、
月下叩门（贾岛）、松风煮茗（陆羽）、寒江独钓（柳宗元）、疏影暗香（林逋）、
富春山居（黄公望）。一个名字给一幅画，但**名字服从配色**，不反过来。

### 架构
`QusheSkin(id, name, light, dark)` 回到成对；`Prefs.skinId` 单值（键改成 `skin_id_v2`，
避开 1.8 那版 `light_skin_id`/`dark_skin_id` 的残留）；
`QusheColors.skin` 单数；色卡页一张卡左右两半（`MiniSwatch`）。

⚠️ 教训：重写 `verify.py` 的 `check_skins()` 时，用于定位的结束标记

## 2.1.0 深色底降饱和 + 新增黑白灰默认（22:00）

用户看完 2.0.0 的反馈，四条都很具体：
1. 深色"单看背景色感觉有点浓，有一种雾蒙蒙的感觉"，只有蓝色那套稍好
2. 需要一个黑白灰的默认配色
3. 松风煮茗、富春山居"黄不拉几绿不拉几，不够纯，脏脏的"
4. 不必所有配色都温馨，温馨两三个就够
5. 名字：富春山居/雪夜访戴/月下叩门不好听；**雪夜访戴（蓝）更适合叫「寒江独钓」**

### ★ "浓/雾"的根因是深色底的饱和度，不是明度
旧深色底按色相实打实配（深绿 #0F1B12、深金 #1D1709），最暗通道只有 9~16 ——
色相全压在最暗处，满屏就是一坨洗不干净的深色。
现在统一成"深灰里带一丝色相"：最暗通道 ≥20、S≈0.30、V≈0.118，
底/卡对比从 1.13 提到 1.19（卡片能浮起来，不再糊成一片）。
**判断方法**：算 `max(rgb)-min(rgb)`，8~10/255 是"看得出色相但不浓"，
超过 18 就发脏；同时最暗通道低于 18 会失去层次。

### 删掉两套"脏"的
- 富春山居（橄榄 #77703A）直接删 —— 橄榄色相 60-70° 天生"黄绿不分"
- 松风煮茗重做成「秉烛夜游」：主色 #86682C（色相 40°，纯琥珀），不再往绿偏
- **金/黄系的色相必须压在 35-42°，一旦超过 50° 就滑进橄榄区间，看起来就脏**

### 八套（默认那套排第一）
见素抱朴（黑白灰）/ 空山新雨（绿）/ 寒江独钓（蓝）/ 沧浪之水（青）/
暮山凝紫（紫）/ 落霞孤鹜（橙）/ 秉烛夜游（金）/ 疏影暗香（粉）
温馨的只有 3 套（落霞/秉烛/疏影），其余偏冷静极简 —— 用户明确说不用都温馨。

命名：见素抱朴（老子）、空山新雨（王维）、寒江独钓（柳宗元）、沧浪之水（屈原）、
暮山凝紫（王勃"烟光凝而暮山紫"）、落霞孤鹜（王勃）、秉烛夜游（李白）、疏影暗香（林逋）。
