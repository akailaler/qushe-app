# 2026-10-29

## 1.5.0（皮肤系统 / 下滑透出上一级 / 顶部提示）

### ① 下滑退出要"透出上一级画面"
原来会话页 `.background(Ink)` + `PhotoLayer` 也铺了一层不透明 Ink ⇒ 下拉时背后一片黑。
改法：
- 三个位移量（offsetX/offsetY/dismissProgress）从 `if (current != null)` 内部**提到外面**，
  否则根背景的 modifier 读不到；
- 根背景改成 `.drawBehind { drawRect(Ink.copy(alpha = 1f - pull)) }`，
  `pull = offsetY.value / (屏高 × 0.22)` —— **在绘制阶段读 Animatable，不触发重组**；
- `PhotoLayer` 不再自己铺底色（它一铺就把下面盖死）；
- 四处 `chromeAlpha` 乘上 `(1 - pullAlpha())`，否则顶栏/底栏会孤零零浮在首页上。
AppRoot 里主界面**一直都在**（`Box { Scaffold{...}; when(session){...} }`），所以透出是免费的 ——
这一点先确认了结构才动手。

### ★ 皮肤 = 一个色相 + 浅/深两版（和「深浅模式」正交）
`QusheSkin(id, name, light: QushePalette, dark: QushePalette)`；
每套只写 11 个种子色，其余由 `skinPalette()` 推导：
- surface2/3 = lerp(卡片色, 文字色, 6% / 13%)（深色往上提、浅色往下压）
- 浮层：深色半透明黑、浅色半透明卡片色（78% / 82%）
- 渐变遮罩：深色 = 底色带 80%/90% 透明度，浅色 = 透明
**加一套皮肤只改一处**，`QusheSkins` 列表顺序即色卡页顺序。
`ForceDarkPalette` 改成用 `QusheColors.skin.dark`（不是默认那套），否则浅色皮肤的视频页会突变。

### ★★ 设计稿的主色不能直接当"选中态文字色"
给的柔桃 `#E8BFB0` 放在 `#FFF9F4` 上对比度只有 ~1.7，而 `AccentKeep`
同时用于底部导航选中文字、星形、勾选 —— 会糊成一片。
做法：**用对比度反算**，脚本按色相只调明度，把关键配对压到目标值：
正文 ≥10、次要 ≥4.6、提示 ≥3.1、删除 ≥4.0（浅色）/ 4.6（深色）。
这套脚本很好用：给定 (底色, 原色, 目标) 二分出最近的可读色，保持色相不变。
**以后加皮肤先跑这个，再肉眼确认。**

### ② 顶部提示
`左右滑下一张 · 上滑删除 · 下滑退出`（胶囊会自动变宽，不用改布局）。

### ③ 色卡页
`ui/settings/SkinPicker.kt`：Dialog 全屏 + 2 列网格，每张卡**左右各一半**（浅/深），
里面用该皮肤自己的颜色画小色块（不能用当前主题画，否则所有卡长得一样）。
设置页第四颗胶囊「更多」，选了皮肤后显示皮肤名。

## 1.6.0 · 配色扩到 10 套 + 一轮 UI 评审（20:20）

### 新增 5 套，原有 5 套全部改四字名
素白玄墨（默认）/ 暖桃初雪 / 新茶初雨 / 燕麦秋声 / 远山如黛 /
烟粉旧梦（莫兰迪灰粉）/ 睡莲静水（莫奈）/ 赤陶晚照（塞尚）/
椰影暖沙（高更）/ 青苔石阶（苔庭）。

**取色方法**（这条最值得记）：油画的彩度不能直接搬，会变糖水；
只取它的**明度关系**，彩度压到"能长时间看"的程度。
每套只挑一个色相，四个分类色（照片/截屏/视频/文件夹）做小幅偏移，
不从别的色系借色 —— 否则 10 套互相串味（"雾蓝"里冒出一个橙就像别人的界面）。
唯一例外是删除色，有语义，必须是红。

### ★ 发现：原来四套浅色皮肤的「主色」全都不达标
`AccentKeep` 同时是底部导航选中文字（12sp）的颜色，而四套浅色的
对比度只有 2.8–4.0（要 4.5）。默认那套的绿 `#0E9C77` 也只有 3.19。
**这不是"配色不好看"，是"字读不清"**，所以统一压深到 ≥4.5 再落地
（默认绿 → `#0B8062`，暖桃 → `#9C6454`，奶绿 → `#54796A`，
燕麦 → `#7E6B59`，雾蓝 → `#567389`）。

### 这一轮顺手改的 UI 问题
1. 配色入口从「深浅模式」那排的第四颗胶囊（写着"更多"）**独立成一行**：
   原来它和三种深浅模式长得一模一样，会被读成"第四种模式"；
   "更多"也没说是更多什么；四字名一排四颗会挤。
2. 色卡页底部那句"后面还会再加几套，加一套只改一处配色表"删掉 —— 开发者视角，
   用户不关心。副标题改成"左半是浅色效果，右半是深色效果"，原来写的是
   "深浅仍由上面的模式决定"，可这一页是全屏的，用户看不到"上面"在哪儿。
3. 首页副标题 30 字 → 18 字（"不用下决心整理，像刷短视频一样划两下"）。
   原来在 411dp 上会断成两行、第二行只剩一个"下"字。
4. 「整理文件夹」右侧补一个箭头：原来 `showCount=false` 就空着，
   前三张右边都有大数字，这张看着像没加载完；它也确实是唯一"还要再选一步"的入口。

## WeiBack-rs 前端设计体检（2.7.1 基线，只审查未改码）

按 `design-aesthetics-book` + `impeccable` 过了一遍 `tauri-app/src`（7602 行 / 54 文件），
产出 `小工具/weiback-设计体检.md`（26 条：3 个真问题 + 6 个令牌 + P0/P1/P2）。

**★ 唯一真 bug：作者跟踪页的回顶按钮仍会被进度条盖住。**
`AuthorTracking.tsx:961` 用的是 `ScrollToTopButton`（`bottom: 24` 写死、不感知任务状态），
而 `FloatingActions` 2.3 就修过（`bottom: isTaskRunning ? 104 : 24`）——
**同一个动作两份实现，当初只改了一份**。作者跟踪页恰恰最常跑备份。
教训：上次抽了 `MediaBadge`，这次漏了回顶按钮；**凡"同一动作有两份实现"，必须当场合并**。

另两个真问题：`FloatingActions` 的删除按钮 0 选中仍可点（假控件，点了只弹提示）；
`AuthorLibrary.tsx:931` 批量删除确认用 `Modal`（无焦点陷阱、Esc 失效），内容浏览页用的却是 `Dialog`。

**量化底数（可复查）**：字号字面量 **12 档**（含 8/9/10px）、硬编码颜色 **24 处**、
z-index **5 套**（9999 / 1201 / 1100 / 4 / 3）、`drawerWidth = 200` 两个文件各写一遍、
**`fontFamily` 全库只有 1 处**（⇒ 汉字走系统回退、数字走 Roboto，基线对不上）、
空状态文案全库只有 **2 处**。

结论：功能没问题，问题是**主题只定了一套绿，其余各页各写各的**；
补 6 个令牌（中文字体族 / 字阶 / 圆角 / z-index / 深色 surface / 状态色）能消掉约一半问题。

## 1.7.0 · 配色架构重做 + 一整套界面修补（21:00）

用户这次一口气提了六件事，其中两件是架构级的。

### ★ 浅色和深色**拆成两张表**（1.6.0 的"成对皮肤"推翻）
理由说得通：白天要的是一张纸，夜里要的是暗室里的一束光 —— 这两件事不平行，
把深色做成浅色的压暗版，十套里总有一半是凑数的。
- `QusheSkin(id, name, palette)`，只有一份调色板
- `LightSkins` / `DarkSkins` 各五套；`Prefs.lightSkinId` / `darkSkinId`
- `QusheColors.darkSkin` 专门给 `ForceDarkPalette` 用（浅色模式下进视频页也要用对）
- 色卡页改成左右两栏，每张卡用**它自己那套**的颜色画样张（用当前主题画会十张一样）
- **旧 `skin_id` 直接弃用**，不迁移（用户说"原本的配色可以完全抛弃"）

### 十套新配色（名字按奔驰氛围灯那一路：地名 + 色）
浅色：月石初白 / 波罗的海 / 亚马逊晨 / 普罗旺斯 / 托斯卡纳
深色：石墨之夜 / 午夜蓝调 / 紫罗兰夜 / 森林晨雾 / 勃艮第红
用户点名"要有紫色的氛围"：浅色给了「普罗旺斯」，深色给了「紫罗兰夜」。
**取色规律写进了 MEMORY.md**：主色 ≥4.5、分类色必须跨色系（否则首页四张卡糊成一片）。

### 其余四件
1. 底部导航：自绘线性/实心两套。**没引 material-icons-extended**（四个图标不值得让
   debug 包涨十几兆）。星形直接复用已有的 `StarBorder/StarFilled`，只补房子/垃圾桶/滑杆。
   坑：垃圾桶右下角圆弧 sweep 写反（0 应该是 1），会向内凹 —— 用 JDK AWT 按同一组坐标
   渲染出来才看出来。
2. 整理页前三张：顶部一行字 → 三行手势卡（箭头按各自方向来回动 5dp，共用同一个时钟）。
   条件是现成的 `!filmstripVisible && !hintDismissed`（index ≥ 3 自动收起）。
3. 设置页去噪：`SettingBlock` 的 subtitle 改成可空；分组标题退成 13sp 轻标签 +
   组间留白 22dp（原来组间距和块间距一样，整页"一条线接一条线"）。
4. App 图标重画：三张由淡到实的卡片（一叠正在过的照片）。旧图标画的是
   "上箭头=删除、下箭头=收藏"，**下滑早就不做收藏了**，那半张图一直在说假话。

### 验证手段（本机没有真机、Edge headless 起不来）
- 用 **JDK 自带的 java.awt** 写了个 `RenderIcons.java`，按同一组坐标把图标画成 PNG，
  逐张看比例/层叠/重心。PIL 装不上（pypi 被拦），AWT 不用装任何东西。
- 结论：这条链路以后都能用 —— 改图标先出图看，别直接信 path。
