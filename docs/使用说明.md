# 取舍 · 使用说明

> 像刷短视频一样刷自己的相册。不用下决心整理，想起来就划两下。

---

## 它和别的清理工具不一样的地方

| | 取舍 | 常见的清理工具 |
|---|---|---|
| 怎么用 | 一张一张划过去，像刷视频 | 网格里勾选、批量操作 |
| 有没有进度压力 | **没有**。不显示"还剩 N 张"，只显示已经看了多少 | 常常有个进度条催你 |
| 删掉的去哪 | 系统回收站，30 天内能捞回来 | 有的直接永久删除 |
| 联网吗 | **不联网**（只有"检查更新"请求一次版本号） | 普遍上传分析 |
| 要权限吗 | 只申请**读取**照片 / 视频，不要写入权限 | 常见"读写存储" |

它不试图替你判断哪张该删，只把"看一眼、决定去留"这个动作做到最省力。

---

## 30 秒上手

1. 打开应用 → 点「整理照片」→ 允许访问照片；
2. **左右滑**一张张看过去；
3. 不想要的**往上滑**，想留着的**直接滑走**就行。

前 3 张会显示操作提示，之后自动收起 —— 不用背。

---

## 四个入口

| 入口 | 什么时候用 |
|---|---|
| **整理照片** | 日常清相册，从全部照片里随机抽一组（每组多少张可在设置里改） |
| **整理截屏** | 截屏单独成组，废片率最高，删起来最爽 |
| **整理视频** | 视频单独成组，上下滑切换 |
| **整理文件夹** | 只清某个具体目录（Download、Weixin、Camera 之类）。同名文件夹里照片和视频都有时，点进去会让你选整理哪一类 |

首页底部「到目前为止」是你攒下的成果：看过多少、删了多少、省了多少空间。
**长按「已删除」那一格可以清零**（只清计数，照片一张不动）。

## 手势

### 看照片（整理照片 / 整理截屏）

| 动作 | 效果 |
|---|---|
| 左右滑 | 上一张 / 下一张 |
| **上滑** | 删除（进系统回收站） |
| **下滑** | **退出这一组**，回到上一级 |
| 单击 | 收起 / 展开界面（按钮、缩略图条、提示） |
| 双击 | 喜欢或收藏（在设置里选哪个） |
| 双指捏合（在 1× 时） | 进入「回到那天」 |
| 放大之后 | 单指拖动是看局部，不会误触发上滑 / 下滑 |

### 看视频（整理视频）

| 动作 | 效果 |
|---|---|
| 上下滑 | **切换视频**（视频流里上下滑是"下一个"，不是退出） |
| 长按 | 2× 速看 |
| 双击 | 喜欢或收藏 |
| 侧边按钮 | 喜欢 / 收藏 / 删除（左右位置可换） |

### 回到那天（某一天的照片墙）

| 动作 | 效果 |
|---|---|
| 左右滑 | 一整天连着看，按时间排、保留原图比例 |
| 点某一格 | 放大成单张，底部 `i` 展开完整信息 |
| 放大后**下滑** | 退回照片墙 |
| 墙上某格**上滑** | 标记删除（松手后这格收缩，后面的补位） |

### 收藏 / 喜欢页

| 动作 | 效果 |
|---|---|
| 点缩略图 | 应用内大图预览（不跳到别的应用） |
| 预览里 | 左下红心、右下星形、右上删除；大图**下滑退出** |
| 「照片 / 视频」右边的「纯观看」 | 开了之后任何操作都不改动内容（防误删） |

> 缩略图本身**只能点开看**，没有任何"长按就改数据"的隐藏操作 ——
> 要改就去预览里按按钮，路径是看得见的。

---

## 喜欢 ≠ 收藏（最容易混的一处）

| | 图标 | 存在哪 | 会同步到系统相册吗 |
|---|---|---|---|
| **喜欢** | ❤️ 红心 | 只在取舍里 | 不会。随手标记，不用担心污染相册 |
| **收藏** | ⭐ 星形 | 取舍 + 系统相册的「收藏」 | 会（默认自动同步） |

一句话：**想留着但不想惊动相册 → 点红心；想让系统相册也认这份收藏 → 点星星。**

---

## 删除与回收站

- 「上滑删除」进的是**系统回收站**（相册里的「最近删除」），30 天后才真正消失；
- 每次删除由**系统**弹一次确认 —— 这是 Android 对第三方应用的强制要求，
  不是应用多问一遍（关不掉）；
- 取舍里的「回收站」页会显示每张**还剩几天**，点开可以恢复；
- 设置里可以关掉「删除进回收站」，改成就地永久删除（不建议）。

---

## 收藏同步：两个已知限制，先说在前面

设置 → 收藏里有三项：**自动同步**、**立即同步**（把攒下的收藏补写进系统相册）、
**同步系统收藏到这里**（把系统里手动收藏的收进来）。

1. **只做加法**：在取舍里取消收藏，系统相册那边**不会**跟着取消；
2. **不是所有手机都支持**：部分机型（如 MIUI 12.5）的相册根本不读也不写这个收藏标记，
   这时反向同步会读到 0 条 —— 是系统限制，不是没同步成功。

小米等机型的相册刷新很慢，同步完可能**要重开相册、甚至重启**才看得到。

---

## 设置里值得改的几项

| 项 | 为什么值得改 |
|---|---|
| **外观 · 深浅模式** | 默认深色；看图看片的界面（预览、视频）永远深色，浅色只影响列表 |
| **每组数量** | 一次抽多少张。太少不够刷，太多做不完 |
| **缩略图网格** | 两列图更大、三列一屏看得更多（收藏、回收站、文件夹都跟着变） |
| **只抽没看过的** | 看过的本轮不再出现，刷完一轮自动开新一轮 |
| **双击画面做什么** | 喜欢 or 收藏 —— 取决于你更常用哪个 |
| **操作栏** | 视频侧边按钮放左边还是右边（单手操作建议右侧） |

---

## 隐私与数据

- **不联网**。全应用只有「检查更新」会访问一次 GitHub 的公开版本号接口，不带任何标识；
- 不需要写入权限：只读照片 / 视频，删除通过系统 API 发起、由系统执行；
- 没有账号、没有埋点、没有云备份。
  代价要说清楚：**卸载或换机后，喜欢 / 收藏记录和统计会清零**（照片本身在相册里，不受影响）。

## 常见问题

**Q：删了的照片去哪了？**
手机相册的「最近删除」，30 天内都能恢复。取舍的「回收站」页能看到剩余天数。

**Q：为什么这类界面在浅色模式下还是黑的？**
大图预览、视频页固定深色 —— 浅色底会把照片衬得像贴在白板上。浅色只作用在列表和缩略图墙。

**Q：缩略图上那些小角标为什么不跟着变浅？**
角标压在**你的照片**上，底图什么颜色都有可能。深底浅字在任何照片上都读得出来，
浅底深字则会在一张深色照片上直接消失。

**Q：统计数字怎么清零？**
长按首页或设置页「到目前为止」里的**「已删除」**那一格，会弹确认框。

**Q：换手机后收藏还在吗？**
不在。应用不做云备份（也不联网），记录只在本机。

**Q：检查更新说「已是最新」，但我看到有新版本？**
它读的是 GitHub 的 latest release，可能有几分钟缓存，过一会儿再点一次。
