# 取舍 · 使用说明

像刷短视频一样刷自己的相册：一张一张划过去，不想要的划掉，想留的划走。
不用下决心整理，想起来划两下就行。

---

## 三步上手

1. 点「整理照片」，允许读取照片；
2. 左右滑，一张张看过去；
3. 不想要的**往上滑**，想留着的**直接滑走**。

前 3 张有操作提示，之后自动消失，不用记。

---

## 四个入口

| 入口 | 用来做什么 |
|---|---|
| 整理照片 | 从全部照片里随机抽一组 |
| 整理截屏 | 截屏单独成组，废片最多 |
| 整理视频 | 视频单独成组 |
| 整理文件夹 | 只清某个文件夹，比如「下载」「微信」 |

首页下面的「到目前为止」是攒下来的成果：看过多少、删了多少、省了多少空间。
长按其中的「已删除」，可以把这个数字清零。

---

## 手势

### 看照片

| 动作 | 结果 |
|---|---|
| 左右滑 | 上一张 / 下一张 |
| 往上滑 | 删除 |
| 往下滑 | 退出 |
| 点一下 | 收起 / 展开按钮 |
| 双击 | 喜欢或收藏 |
| 双指捏合 | 进入「回到那天」 |

照片放大以后，单指拖动是看局部，不会误触发删除或退出。

### 看视频

| 动作 | 结果 |
|---|---|
| 上下滑 | 换下一个视频 |
| 长按 | 两倍速 |
| 双击 | 喜欢或收藏 |
| 侧边按钮 | 喜欢 / 收藏 / 删除 |

### 回到那天

| 动作 | 结果 |
|---|---|
| 左右滑 | 那一天的照片连着看 |
| 点某一张 | 放大 |
| 放大后往下滑 | 退回照片墙 |
| 在照片上往上滑 | 标记删除 |

### 收藏页

| 动作 | 结果 |
|---|---|
| 点缩略图 | 打开大图 |
| 大图里 | 左下红心、右下星星、右上删除 |
| 大图往下滑 | 退出 |
| 打开「纯观看」 | 之后怎么点都不会改动内容 |

---

## 喜欢和收藏不一样

|  | 存在哪 |
|---|---|
| **喜欢**（红心） | 只在取舍里，不碰手机相册 |
| **收藏**（星星） | 会同步到手机相册的「收藏」 |

想留着但不想惊动相册，点红心；想让相册也认，点星星。

---

## 删除和回收站

- 删除后进「回收站」，30 天内都能恢复；
- 每次删除手机会问一次「确认删除」—— 这是安卓的规定，去不掉；
- 「回收站」里每张都写着还剩几天，点开就能恢复。

---

## 收藏同步到手机相册

- 打开后，在取舍里点星星，手机相册的收藏夹里也会出现；
- **只加不减**：在取舍里取消收藏，相册那边不会跟着取消；
- 有些手机的相册不认这个标记，那就同步不过去 —— 不是没成功。

---

## 它不联网

- 除了「检查更新」查一次版本号，不上传任何东西；
- 不用登录，没有账号；
- 换手机或卸载重装后，喜欢 / 收藏和统计会清零。照片本身在相册里，不受影响。

---

## 常见问题

**删了的照片去哪了？**
在「回收站」里，30 天内都能恢复。

**为什么这个页面在浅色模式下还是黑的？**
看图、看片的页面固定深色，浅色只作用在列表上。

**统计怎么清零？**
长按首页「到目前为止」里的「已删除」。

**不喜欢这个配色，能换吗？**
能。设置 → 外观 → 点「配色」，里面有十套（素白玄墨、暖桃初雪、新茶初雨、
燕麦秋声、远山如黛、烟粉旧梦、睡莲静水、赤陶晚照、椰影暖沙、青苔石阶）。
每张色卡左半是浅色效果、右半是深色效果，选完还是跟着上面的「深浅模式」走。

**检查更新说已是最新，但我看到有新版本？**
可能有几分钟延迟，过一会儿再点一次。
