# 2026-10-31

## 2.0.0 配色推翻重做：配色优先，一套成对（22:20）

用户否掉了「西湖景 + 浅深分开选」这一版，两个要求很关键：
1. **配色本身要好看协调，不能为了名字硬凑** —— 名字只是配色的注释，不是配色来源。
2. **回到"一套含浅深"，但色卡保持左右并排**：挑一次整套生效，不要分开选两道题。

### 做法
先定 8 套配色（绿 / 蓝 / 橙 / 紫 / 金 / 青 / 粉 / 橄榄），跑对比度，
**再用 AWT 画总览图看整体** —— 第一版的深色底明度全挤在 L* 8–12，八套缩在图里像一堆黑；
把底色明度分三档（#0A1A19 / #15101F / #241610）后才有层次。**这一步必须做，
只看单个色值判断不了"八套放在一起好不好看"。**

名字是最后配的，八个典故：空山新雨（王维）、雪夜访戴（王子猷）、落霞孤鹜（王勃）、
月下叩门（贾岛）、松风煮茗（陆羽）、寒江独钓（柳宗元）、疏影暗香（林逋）、
富春山居（黄公望）。一个名字给一幅画，但**名字服从配色**，不反过来。

### 架构
`QusheSkin(id, name, light, dark)` 回到成对；`Prefs.skinId` 单值（键改成 `skin_id_v2`，
避开 1.8 那版 `light_skin_id`/`dark_skin_id` 的残留）；
`QusheColors.skin` 单数；色卡页一张卡左右两半（`MiniSwatch`）。

`verify.py` 直接 NameError。**按标记区间替换前，先确认区间里只有想删的东西。**
